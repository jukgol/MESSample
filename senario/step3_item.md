# Step 3: 품목 도출 (step3_item.md)

BOM 설계서(레시피)를 기준으로 시스템에 등록해야 하는 구체적인 품목(Item) 목록을 도출하여 마스터 테이블(`ITEM`)에 등록합니다.

---

## 🛠️ Item 마스터 테이블 데이터

| item_id (고유 ID) | item_name (품목명) | item_type (품목 구분) | unit (기본 단위) | description (품목 상세 설명) |
| :--- | :--- | :--- | :--- | :--- |
| **101** | 밀가루 | 원자재 | kg | 공통 반죽용 밀가루 원재료 |
| **201** | 신라면 분말스프 | 원자재 | ea | 신라면용 국물 조미 스프 |
| **202** | 진라면 분말스프 | 원자재 | ea | 진라면용 국물 조미 스프 |
| **203** | 신라면 건더기스프 | 원자재 | ea | 신라면용 야채/고기 스프 |
| **204** | 진라면 건더기스프 | 원자재 | ea | 진라면용 야채/고기 스프 |
| **301** | 신라면 포장비닐 | 원자재 | ea | 신라면 완제품 밀봉용 포장 부자재 |
| **302** | 진라면 포장비닐 | 원자재 | ea | 진라면 완제품 밀봉용 포장 부자재 |

---

## 💡 시나리오 검증 포인트

1. **품목 유형(item_type) 분류 정합성**:
   * 각 품목이 `원자재`, `반제품`, `완제품`으로 규정된 코드를 정상적으로 지니고 있어, Lot 등록 및 BOM 계산 시 알맞은 규칙이 적용되는지 검증합니다.
2. **기본 단위(unit) 일관성**:
   * BOM의 소모량 계산 시, 해당 품목 마스터의 `unit`과 소모 지시 단위가 수학적으로 호환되는지 확인합니다. (예: kg ➡️ g 변환 로직 처리)
