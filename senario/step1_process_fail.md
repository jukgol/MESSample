# Step 1-1: 공정별 생산 실패 케이스 (step1_process_fail.md)

1. 시작 전 (가동 전 사전 확인)
- 실패: 가동 전 필요한 모든 원자재의 재고가 지시량보다 부족할 때 -> 해결: 동일 품목의 다른 가용 Lot이 있는지 확인하고, 대체 Lot도 없다면 공정 가동 전체를 즉시 멈춤

2. 10번 반죽 공정
- 실패: 밀가루 재고가 부족하거나 선택된 Lot 상태가 '보류(Hold)'일 때 -> 해결: 대기 상태의 다른 밀가루 Lot이 있는지 조회하고, 없을 시 공정 전체를 즉시 멈춤

3. 20번 제면 공정
- 실패: 선행 공정의 반죽 Lot이 아직 작업 중이거나 존재하지 않을 때 -> 해결: 반죽 Lot 상태가 완료될 때까지 대기하거나, 완료 Lot이 없으면 공정 전체를 즉시 멈춤

4. 30번 유탕 공정
- 실패: 면발 Lot이나 튀김용 기름 중 한 가지라도 재고가 부족할 때 -> 해결: 창고의 다른 가용 Lot이 있는지 확인하고, 대체 Lot이 없으면 공정 전체를 즉시 멈춤

5. 40번 포장 공정
- 실패: 면발, 스프, 비닐 등 최종 자재 중 일부가 부족할 때 -> 해결: 대기 중인 여러 스프/비닐 Lot을 순차 분할하여 차감하고, 최종 합산 수량이 부족하면 공정 전체를 즉시 멈춤
